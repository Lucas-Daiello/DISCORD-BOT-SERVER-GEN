ESTE CÓDIGO FOI CRIADO COM AJUDA DE INTELIGÊNCIA ARTIFICIAL
O OBJETIVO DESTE PROJETO É PERMITIR QUE OS USUÁRIOS CRIEM SERVIDORES DO DISCORD
DE FORMA RÁPIDA E FÁCIL, USANDO UM PROMPT PERSONALIZADO PARA GERAR A ESTRUTURA DO
SERVIDOR EM FORMATO JSON.

Como usar:

1. Baixe o código-fonte do repositório se ainda não o fez.
2. Instale as dependências necessárias usando o comando `pip install -r requirements.txt`.
3. Coloque o token do seu bot do Discord no arquivo .env.
4. Execute o script principal usando o comando `python main.py`.
5. Copie e cole o prompt do arquivo 'recreate prompt.txt' em qualquer inteligência artificial
de sua escolha (como o ChatGPT), mude onde está escrito {TEMA} para o tema do seu servidor
que deseja criar, adicione/edite as últimas linhas para suas preferências e envie.
A resposta do chat será um código em JSON, essa é a estrutura do seu servidor.
6. Abra o discord e em qualquer canal de texto, envie o comando /recreate e quando pedir, envie o código JSON gerado pela IA
O seu servidor será recriado automaticamente com base na estrutura fornecida.

É permitido o uso do código para fins comerciais, sem necessidade de crédito ao autor original.
Sinta-se à vontade para modificar e adaptar o código conforme necessário para atender às suas
necessidades específicas.
